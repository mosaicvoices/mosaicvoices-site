# Mosaic Voices — Static site scaffold

This is a minimal, easy-to-manage static-site starter for the Mosaic Voices design.

What I created
- `index.html` — single-page scaffold with panels for Cover / About / How it works / Gallery / Get involved
- `styles.css` — base styles and color tokens (teal, mustard, cream)
- `script.js` — tiny progressive-enhancement script for the interest form

Run locally
- Using Python 3 (quick):

```powershell
python -m http.server 8000
# then open http://localhost:8000 in a browser
```
